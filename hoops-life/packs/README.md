# Content packs

Drop `media-pack-1.js` … `media-pack-20.js` here (generate them with the prompt in `CHATGPT_PROMPT.md`).
The game loads them automatically on startup and mixes their lines into headlines and reactions.

- Lines whose placeholders can't be filled in a situation are skipped automatically.
- Era variants use a key suffix like `game.blowout@60s`.
- `ideas-*.md` files are for planning new situations; the game doesn't load them.
